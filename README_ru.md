# NIC-Arduino — семейство NIC Arduino

**Сторона данных NIC в одном месте: формат лога MLA, его опциональные дополнения, клей, сейсмо-экспорт и просмотрщик VDE.**

Это зонтик над всем **семейством Arduino** NIC — программной/информационной
стороной, выросшей вокруг Arduino. Каждый компонент сохраняет своё имя и свой
README и остаётся пригодным к самостоятельному использованию (drop-in, в стиле
Arduino-библиотеки) — они просто живут вместе здесь, чтобы было ясно, что к чему
относится.

```
NIC-Arduino  (семейство Arduino)
├── NIC-MLA       основа — контейнер/формат лога NIC-MLA
├── NIC-DMD       опционально: сжатие NIC-DMD
├── NIC-KSF       опционально: шифрование NIC-KSF
├── NIC-GLUE-IN   клей: запись данных в лог MLA
├── NIC-GLUE-OUT  клей: чтение / экспорт лога MLA (CSV, SQLite, …)
├── NIC-MSEED     сейсмо-экспорт: лог MLA → miniSEED (международный стандарт)
├── NIC-IAGA      геомаг-экспорт: лог MLA → IAGA-2002 (INTERMAGNET / SuperMAG)
└── NIC-VDE       просмотрщик VDE (Volkov Data) — просмотр и экспорт логов MLA
```

## Как это складывается вместе

**MLA — это основа.** NIC-узел логирует отсчёты в контейнер NIC-MLA — это сердце
стороны данных, и оно самодостаточно. Начиналось всё с тривиальных пары строк, и
даже обзаведясь более богатым набором возможностей, результат остался таким же
тривиальным в использовании; просто опций теперь чуть больше.

Всё остальное **опционально, наслоено поверх MLA — бонус, а не требование:**

- **dmd/** — если нужно хранить отсчёты *сжатыми*, MLA умеет записывать их через
  NIC-DMD. Чистый MLA прекрасно работает без него.
- **ksf/** — если нужно хранить отсчёты *зашифрованными*, это делает NIC-KSF.
  Тоже опционально.
- **glue-in/ · glue-out/** — клей, который пишет в лог MLA и читает/экспортирует
  из него. Библиотеки — это детали; клей соединяет их под задачу.
- **mseed/** — сейсмо-экспорт. Сейсмограф NIC-Quake / NIC-Heimdall сохраняет в
  MLA; когда нужен *международный* сейсмологический формат, mseed превращает этот
  лог MLA в miniSEED (ObsPy / SeisComp / FDSN). Создан для сейсмо-платформы; то,
  что его может использовать кто-то ещё, — бонус.
- **iaga/** — геомаг-экспорт. Магнитометр NIC-Gauss сохраняет в MLA; iaga
  превращает этот лог в IAGA-2002 (обменный формат INTERMAGNET и вход SuperMAG
  для вариометров) — калиброванные нТл, `Data Type: variation`.
- **vde/** — просмотрщик VDE (Volkov Data): настольное приложение для просмотра и
  экспорта логов MLA.
